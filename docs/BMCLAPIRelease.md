# Prism Launcher BMCLAPI fork for Windows

This is a community build based on Prism Launcher 11.1.1. It is not an official Prism Launcher release. The Windows executable is unsigned.

Unzip the portable package into a folder you can write to, then run `prismlauncher.exe`. In **Settings → Services → Minecraft Downloads**, select **Official**, **BMCLAPI**, or **Custom**. A custom source needs a BMCLAPI-compatible HTTPS base URL. If a mirror download fails, the launcher retries the official URL.

此版本是基于 Prism Launcher 11.1.1 的社区构建，并非官方版本；Windows 程序未签名。解压便携版 ZIP 后运行 `prismlauncher.exe`。在**设置 → 服务 → Minecraft Downloads** 中选择 **Official**、**BMCLAPI** 或 **Custom**；自定义地址必须是兼容 BMCLAPI 的 HTTPS 基础地址。镜像下载失败时，启动器会重试官方地址。

`SHA256SUMS.txt` lists the SHA-256 checksums of the portable ZIP and source patch. `SOURCE.txt` records the built commit and upstream base tag. The `licenses` folder contains available dependency notices; `LICENSE.txt` is the Prism Launcher license.
